# 自动定位标注说明（11 张"无字"参考图）

## 这次做了什么
用 **GroundingDINO-tiny**（开集目标检测模型）对 `data/raw/reference_wuzi/` 的 11 张图，
自动检测 23 个出行物品，给出**像素级边界框**。你只需**看图核对**。

## 产物（都在 data/labeled/）
| 文件 | 用途 |
|---|---|
| `overlays/<图名>_bbox.jpg` | **看图核对用**：原图上画框，框边标注"物品名 + 置信度" |
| `locations_review.csv` | 机器草稿：每张图 × 23 项，TRUE=检出（含 x1,y1,x2,y2,score,location），FALSE=未检出 |
| `locations_corrected.csv` | **你改好的版本**（`gdino_to_train.py` 优先读它；没有则退回 review） |
| `detections.json` | 程序用结构化结果（框坐标像素值） |

## 怎么核对
1. 打开 `overlays/` 里的对照图，对照每个框右上角的标签。
2. 发现 **错标 / 漏标 / 框太偏** → 记下来（或在 `locations_review.csv` 直接改 `present` 与坐标）。
3. 核对完 → 把改好的表存为 `locations_corrected.csv` → 转训练数据（`python gdino_to_train.py`）→ `train.py`。

## 已知局限（重要，务必逐张过一遍）
- **标签可能张冠李戴**：框能落到真实物体上，但"是什么"会认错
  （例：参考15 把太阳镜框成"口罩"、把镜头框成"耳机"）。位置可用，名字要你确认。
- **偶尔有超大框**：低置信度误检（score<0.35 尤其可疑，如某图"常用药品"框住整张图）——删掉即可。
- **物品少的图检出少**：如参考5（几乎全是卫生巾）只检出 3 项，属正常。
- 总体规律：**框的位置可信度 > 标签正确度**。

## 为什么不用 Qwen2.5-VL（原方案已弃用）
最初用 Qwen2.5-VL-3B 做 grounding，实测**不可靠**：
- 同一张图不同次运行结果差异极大（一次出 9 个不同框，一次退化成 1 个）；
- 多个物品被套用**同一个框**（假标注，如参考5 的 18 项坐标完全相同）；
- 整张漏检常见（参考15 的存在性判断全 false，而图里其实摆满物品）。
故改用品类专用的 GroundingDINO，位置精度和区分度明显更好。

## 想调检测松紧
```bash
python gdino_detect.py --box_th 0.30 --text_th 0.25   # 默认：框多、可能误检
python gdino_detect.py --box_th 0.40 --text_th 0.30   # 更严：框少、可能漏检
```
`--box_th` 越低框越多（易误检），越高框越少（易漏检）。
